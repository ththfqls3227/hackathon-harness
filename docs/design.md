# 설계 선택지

실제 과제와 제공 Codex의 기능은 아직 확인하지 않은 사전 준비 패키지다. v0.1.0에서 경량 스킬형을 채택했고 v0.2.0에서는 [CodexClaw 검토](codexclaw-review.md)를 통해 기존 진행·검증·재개 절차를 보강했다.

v0.3.0에서는 제공된 안내와 체험 UI의 구성을 대조해 [응시 규정](exam-contract.md)을 공통 진입점에 연결했다. 체험 UI를 관찰한 것과 CLI·MCP·하네스가 실제 동작한 증거는 구분한다. 문서 지침으로 준수를 유도하며 자동 차단이나 감독 기능을 추가하지 않는다.

| 후보 | 가져갈 것 | 적합한 상황 | 비용 |
|---|---|---|---|
| 단일 지침 | AGENTS.md + 명시적 읽기 | 준비 시간이 거의 없거나 기능 지원이 적음 | 긴 작업의 기록 관리가 약함 |
| 경량 스킬 — 현재 채택 | 범위·진행·검증 + 선택적 데이터·UI·도해 스킬 | 과제 형태 미정, 짧은 구현 시간 | 필요한 파일을 골라 읽어야 함 |
| 선택적 역할 분리 | 경량 스킬 + 지원되는 native subagent | 독립 검토나 구현을 병렬화할 여유가 있음 | 응답 대기·병합·사용량 증가 |

## 살릴 작업 방식

- 기능부터 만들기 전에 실제 업무 문제를 확인한다.
- 선택지와 반론을 검토하되 결정을 내린 뒤에는 끝까지 실행한다.
- 모르는 부분과 확인한 사실을 구분하고, 실제 검증 결과로 완료를 판단한다.
- 한 번에 큰 자동화보다 작은 동작을 완성하고 확인한다.
- 중요한 판단의 이유를 짧게 남겨 참가자가 구현을 이해할 수 있게 한다.

## 미리 넣지 않는 것

특정 프레임워크·DB·앱 템플릿, 전체 OMX 런타임, 개인 위키·전역 설정, 기본 MCP, 외부 모델 API, 브라우저 자동화는 포함하지 않는다. 과제 근거가 생기면 허용 범위 내 필요한 부분만 추가한다.

## 체험에서 확인할 것

필수 환경 연결과 편집·저장·터미널 동작을 먼저 확인한다. 시간이 남으면 제공 Codex의 버전·허용 모델·스킬 탐색·native subagent 지원 여부를 확인한다. 미지원 기능 때문에 업데이트하거나 감독 설정을 변경하지 않는다. 경로를 명시해서 문서를 읽는 방식으로 대체한다.

## 이후 함께 정할 것

실무자 질문·문제 정의에 더 투자할지, 구현 속도·검토 분리에 더 투자할지 체험 결과와 사용자의 선호를 보고 조정한다. 새 기능은 설치 시간보다 절약할 시간이 크고 로컬 데이터 경계를 지킬 수 있을 때 추가한다.
