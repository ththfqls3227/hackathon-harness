# 제한된 웹 IDE의 작업 규정

현재 하네스가 적용하는 Codex 전용 응시 프로필이다. 시작·재개 시 읽고, 선택 스킬과 하위 에이전트에도 적용한다. 운영 안내와 실제 과제 규정이 우선한다. 이 문서는 원본 안내문을 재배포한 것이 아니며, 설정이나 권한을 강제하는 프로그램도 아니다.

## 먼저 적용 범위를 확인한다

- 운영자가 명시한 최신 시험별 공지·지시와 실제 과제의 허용 범위를 확인한다. 개인별 접속 안내 메일과 기존 가이드 3종이 충돌하면 메일을 우선하며, 메일에서 다루지 않은 사항은 기존 가이드를 유지한다. 이후 추가 공지의 변경 범위도 확인한다. 일반 플랫폼 튜토리얼, 도구 버튼의 존재, 샘플 README는 본과제의 제한을 완화하는 근거가 아니다.
- 원본 안내를 작업 공간에서 찾지 못하면 이미 확인된 제한을 유지한다. 참가자에게 빠진 허용 범위만 확인하며 안내 PDF·개인 파일·시험 화면의 업로드를 요구하지 않는다. 해결되지 않은 충돌은 해당 동작만 보류하고 독립적인 로컬 작업을 계속한다.
- 시작 응답에 현재 단계, 허용 AI·모델, 실제 작업 루트, 필수 산출물, 남은 시간·절대 종료·후속 단계 시간, 도구 관련 미확인을 짧게 정리한다. 모든 항목의 답을 받기 위해 안전한 읽기 작업까지 멈추지 않는다.

## 참가자의 사전 준비와 일정

다음은 2026년 2차 예선의 접속 안내 메일을 반영한 기준이다. 참가자가 직접 확인하며, 하네스가 접속·동의·감독 준비를 대신 완료했다고 기록하지 않는다.

- 일정은 **2026-10-31 10:00~14:00 KST**다. 09:40까지 접속·준비하고 당일 09:40 발송되는 추가 이메일도 확인한다. 그 추가 공지의 내용은 이 프로필에서 확인된 것으로 간주하지 않는다. 별도 시작 공지를 기다리지 않고 10:00에 시작하며, 지각에 따른 연장·개별 일정 변경·일요일 응시는 없다.
- 사전 체험은 본시험 시작 전 실제 응시 기기·장소에서 한 번, 15분만 가능하다. 감독 앱 연결·촬영 구도·작업 환경을 확인한다. 진입했다는 사실과 체험 완료·본시험 완료를 구분한다.
- Chrome을 사용한다. 노트북·휴대폰 충전, 독립된 폐쇄 공간, 안정적인 인터넷과 실물 신분증을 준비한다. 기존 가이드의 단일 모니터·전체화면·촬영 조건도 유지한다.
- 블루투스 키보드·마우스는 사용하지 않는다. 외장 키보드·마우스는 유선으로 준비하며 노트북 내장 키보드는 사용할 수 있다.
- **Cofa Proctor 앱**은 iOS 최신 버전 업데이트, Android 공식 안내 경로에서 다시 내려받아 설치하는 것이 권장된다. 휴대폰은 안정적인 Wi-Fi에 연결한다. 이는 아래의 **Codex 업데이트 금지**와 구분한다.
- 필요한 본인 확인·웹캠·화면·휴대폰 녹화 절차에는 참가자가 직접 동의하고 참여한다. 정당한 사유 없는 녹화 중단과 운영팀의 재개 요청 불응은 응시 제한·평가 제외 사유가 될 수 있다. 하네스가 동의·연결·녹화·영상 파기 상태를 대신 확인하거나 보장하지 않는다.

## AI·인증·도구 선택

| 대상 | 적용 기준 |
|---|---|
| AI | 제공된 Codex만 사용한다. Claude Code가 설치돼 있거나 튜토리얼에 등장해도 실행·위임하지 않는다. 외부 AI와 별도 모델 공급자 연결도 하지 않는다. |
| 모델·버전 | 메일의 권장 표시명은 **6.1 Sol, 5.6 Terra, 6.0 Luna**다. 권장 목록을 허용 모델의 전체 목록으로 단정하지 않고 제공 환경의 실제 선택지와 규정을 확인한다. 제한된 Astra나 허용 목록 밖 모델을 선택하지 않는다. 표시명에서 CLI 모델 식별자를 추측하지 않는다. 업데이트 권유가 떠도 제공 Codex를 업데이트·교체하지 않는다. |
| 인증 | 제공된 인증을 그대로 사용한다. 개인 API 키·구독·로그인을 추가하지 않는다. 키 값, 인증 파일, 전체 환경변수를 출력·기록·붙여넣지 않는다. 인증 오류는 비밀값 없이 증상으로 신고한다. |
| 승인·설정 | 승인 대기와 실행 중을 구분한다. 승인 요청은 참가자가 내용을 보고 응답한다. 자동 승인·샌드박스 해제·보안/감독 우회 옵션으로 해결하지 않는다. 허용된 MCP 설정과 플랫폼 관리 설정을 구분한다. |
| 하위 에이전트 | 실제 지원되고 허용된 경우에만 제공 Codex의 허용 모델로 제한된 일을 맡긴다. 이 규정과 현재 단계를 함께 전달한다. 역할명·상위 에이전트 지시가 규정 예외를 만들지 않는다. |

운영팀은 과제 풀이에 충분한 토큰을 제공하며 사용량·활용 과정을 평가에 참고할 수 있다고 안내했다. 과제에 필요한 읽기·구현·검증에 사용하고, 같은 자료의 반복 적재나 목적 없는 병렬 호출은 줄인다. 이를 토큰을 적게 쓸수록 고득점이라는 규칙으로 해석하거나 필수 검증을 생략하지 않는다.

## 공개 자료 수신과 자료 반출

공개 저장소의 지침·Skill·하네스·템플릿·코드는 상세 가이드가 허용한 범위에서 활용한다. Skill·MCP·Plugin·GitHub 자료는 과제에 필요한 용도로 허용된 clone·다운로드 경로를 사용할 수 있다. 사용 저장소는 공개 상태여야 하며 비공개 저장소는 사용하지 않는다. 필요한 정보는 플랫폼 안에서 허용된 AI를 통해 확인한다. 외부 브라우저로 직접 이동하거나 개인 PC의 비공개 파일·스킬을 업로드하지 않는다. 차단된 반입을 다른 형식·경로로 우회하지 않는다.

도구를 추가하기 전에는 목적, 공개 출처, 실행 코드·권한, 네트워크 목적지와 전송 내용, 인증 요구를 확인한다. MCP 설정 탭이나 빈 JSON이 보인다는 사실만으로 연결·허용·무전송이 검증된 것은 아니다. 필요한 로컬 도구는 사용할 수 있지만, 시험 내용을 외부에 보내는 도구는 사용하지 않는다. 확인이 안 되면 기존 로컬 도구를 쓴다. 기본 MCP를 자동 설치할 필요는 없다.

- 문제·답안·파일·결과·대화·로그를 외부 API, 검색 질의, 이슈, 원격 저장소, 클라우드, 원격 이미지·렌더링 서비스로 보내지 않는다. 공개 자료 요청의 URL·본문에도 시험 내용을 넣지 않는다.
- 시험 작업 공간에서는 git push, 외부 배포, 공유 링크나 새 터널 생성을 하지 않는다. 서비스 확인에는 플랫폼이 제공한 미리보기를 쓴다.
- 외부 자료로 결과물 전체를 대체하지 않는다. 필요한 부분을 실제 요구에 맞게 이해·수정·검증하며 출처와 사용 범위를 과제 안에 남긴다. 사용한 공개 저장소는 **2차 예선 결과 통지 전까지** 공개 상태로 유지한다. 사용 자료·제출물·작업 이력은 검토 대상이므로 실제 사용 내역을 숨기거나 꾸며내지 않는다.

## 화면·메신저·파일

- Computer Use, 자동 클릭·입력, Playwright·브라우저 MCP·headless 브라우저를 통한 화면 조작과 캡처를 사용하지 않는다. 참가자에게도 문제·답안·시험 화면을 OS 단축키로 캡처하거나 외부 AI에 붙여넣으라고 요청하지 않는다. 내장 AI에게 보여줄 목적이어도 캡처·업로드 금지를 우회하지 않는다.
- Codex는 작업 공간의 허용된 파일을 직접 읽는다. 화면 상태는 참가자가 텍스트로 설명하고, 내부 복사·붙여넣기도 해당 단계의 허용 범위를 따른다. 스크린샷이 없다는 이유로 검증됐다고 꾸미지 않는다.
- 참가자가 메신저와 미리보기를 직접 조작한다. 업무 판단은 업무 담당자에게, 화면 사용법·제출 절차는 플랫폼 도우미에게 구분해 묻는다. 플랫폼 오류, 감독 앱의 연결·녹화 오류 등으로 정상 응시가 어려우면 참가자가 **시험 환경 내 문의 버튼**으로 발생 시각과 증상을 접수한다. Codex·에디터·반복 오류도 연결·녹화 오류가 아니라는 이유로 신고 대상에서 제외하지 않는다. 오류 설명은 시각·증상을 중심으로 작성하고 인증값·개인 접속 링크를 덧붙이지 않는다. 운영팀이 원인과 응시 영향을 확인해 개별 안내하며, 신고만으로 시간 연장이나 구제를 확정하지 않는다. 질문 초안과 실제 전송·답변을 구분한다.
- `pwd`와 제한된 파일 목록으로 현재 위치를 확인하고 실제 과제 README·입출력 경로를 기준으로 작업 루트를 정한다. 홈 디렉터리나 샘플의 `/workspace`를 임의로 과제 루트로 가정하지 않는다. 기존 설정·제공 자료는 덮어쓰지 않는다.
- 웹 서버는 안내에 따라 `0.0.0.0`에 바인딩하고 실행 로그의 실제 포트·경로를 확인한다. 미리보기의 기본 포트 `3000`은 고정 요구가 아니다. 참가자에게 실제 포트와 경로를 전달하며 서버 터미널을 유지한다. 임의의 접속 URL을 만들지 않는다.
- 파일 저장·실행 결과·HTTP 응답·참가자의 화면 확인을 구분한다. 하네스 파일이나 숨김 파일이 제출 미리보기에 안 보인다고 제출 대상이 아니라고 추정하거나 삭제하지 않는다.

## 제출 상태에 따른 작업 범위

| 상태 | 할 수 있는 작업 |
|---|---|
| 작업 중 | 허용된 AI로 문제 정의·구현·검증·필수 문서 작성. 현재 확인한 사실과 판단을 기록하며, 예상 후속 문항 답안은 만들지 않음 |
| 제출 미리보기 | 타이머가 계속 흐른다. 수정은 참가자가 미리보기를 닫고 작업 화면으로 돌아왔음을 확인한 뒤 수행. 목록은 일부일 수 있음 |
| 제출물 확정·후속 문제 준비 | 파일 수정과 과제 AI 작업을 중단한다. 문항 준비 대기 시간을 추가 작업·답안 준비 시간으로 쓰지 않음 |
| 후속 서술형 | 본인이 직접 답한다. AI 답변·윤문·회고·자료 검색·복사 붙여넣기를 하지 않음 |
| 최종 제출 완료 | 참가자가 플랫폼의 완료 표시·제출 ID·시각·파일 수·크기를 확인. 하네스가 자동 제출하거나 확인을 대행하지 않음 |

작업 제한시간과 시험 전체 종료 중 먼저 닿는 시점을 기준으로 후속 단계·대기·제출 확인 시간을 남긴다. 가이드의 작업 종료 약 10분 전 제출 시작은 권장 여유이며 시간 연장을 보장하지 않는다. 문항 수·대기 시간은 예시 화면으로 확정하지 말고 실제 화면과 최신 공지를 따른다.

단일 모니터·전체화면·웹캠·휴대폰 감독·실물 신분증·충전·기기 규정은 참가자가 직접 확인한다. AI가 연결·본인 확인을 완료했다고 주장하거나 감독 프로세스를 변경하지 않는다. 식음료·이석·촬영 구도처럼 출처가 충돌하는 운영 사항은 시험별 공식 안내를 확인하며, 코딩 하네스가 임의로 허용을 확정하지 않는다.

이 프로필은 준비 저장소 자체의 사전 개발·공개를 막는 규정이 아니다. 그 작업은 사용자 승인 범위에서 수행하며 원본 안내문·개인 응시 링크·스크린샷·시험 내용은 공개 패키지에 포함하지 않는다.
