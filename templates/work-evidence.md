# 작업 근거

과제가 지정한 문서가 있으면 그 문서에 필요한 부분만 합친다. 이 빈 양식 자체를 완료된 기록으로 제출하지 않는다. 작성한 내용은 시험 작업 공간에만 보관한다. 후속 서술형 답안은 작성하지 않는다.

## 시작·재개 상태 — 필요한 항목만

- 현재 단계(작업·미리보기·확정·후속·완료):
- 확인한 시험별 안내와 미해결 충돌(원문·개인 링크는 복사하지 않음):
- 실제 작업 루트·필수 산출물:
- 허용 AI·모델·도구와 미확인 기능(인증값은 기록하지 않음):
- 남은 작업 시간·전체 종료·후속 단계와 제출 여유:

## 필수 작성 항목 — 개수를 정하지 않음

| 항목·출처 | 작성·사용 단계와 AI 허용 근거 | 파일 또는 입력 위치·형식·분량 | 상태·부족한 근거 | 현재 구현·검증 근거 |
|---|---|---|---|---|

파일 저장, 플랫폼 입력, 제출 완료를 구분한다. 읽지 못한 화면 항목은 미확인으로 남긴다. 개발 중 허용된 필수 글을 관리하는 표이며 후속 문항 답안을 준비하는 표가 아니다.

## 결정

| 결정 | 고려한 대안 | 선택 근거 | 이번 제외 범위 |
|---|---|---|---|

AI 제안을 검토한 경우 필요한 항목만 덧붙인다: 원래 제안·출처 / 발견한 문제 / 참가자의 실제 선택·이유 / 변경 전후와 구현 주체 / 검증 결과. 기존 기록이 없어 지금 함께 검토했다면 '현재 검토에서 결정'이라고 적는다. 과거 판단·직접 수정 이력을 만들어 채우지 않으며 변경 없이 유지한 이유도 기록할 수 있다.

## 재개할 때 필요한 기록 — 중단·압축이 있을 때만

이해 점검 기록이 있다면 미응답과 변경된 근거를 함께 확인한다.

- 현재 단계와 최소 구현 범위:
- 변경 파일과 마지막으로 검증한 상태(커밋 또는 파일 변경 내용):
- 마지막 실행 명령·결과와 실제 로그 위치:
- 마지막 저장 확인·앱 프로세스·실제 포트(재개 시 재확인):
- 장애 발생 시각·증상·마지막 성공 작업·신고 상태(비밀값 제외):
- 미해결 문제·검토 지적의 처리 상태:
- 다음 한 가지 행동:

최신 파일과 근거를 다시 확인한 뒤 이어간다. 기록된 성공 이후 수정됐다면 관련 검증은 다시 필요하다.
